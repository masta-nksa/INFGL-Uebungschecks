# Musterlösung: Übungscheck Z4 – Binärbrüche

Bei Aufgaben mit freier Formulierung sind andere Worte richtig, solange der Inhalt stimmt. Die Rechenwege zeigen einen möglichen Weg, nicht den einzigen.

**Aufgabe 1.** Wandeln Sie in eine Dezimalzahl um:  0.101<sub>2</sub> = …

1/2 + 0/4 + 1/8 = 0.5 + 0.125 = **0.625**

**Aufgabe 2.** Wandeln Sie in eine Binärzahl um:  6.25<sub>10</sub> = …

Vorkommateil: 6 = 110<sub>2</sub>

Nachkommateil: 0.25 · 2 = 0.5 → 0;  0.5 · 2 = 1.0 → 1

→ **110.01**<sub>2</sub>

**Aufgabe 3.** Wandeln Sie in eine Binärzahl um:  2.3125<sub>10</sub> = …

Vorkommateil: 2 = 10<sub>2</sub>

0.3125 · 2 = 0.625 → 0;  0.625 · 2 = 1.25 → 1;  0.25 · 2 = 0.5 → 0;  0.5 · 2 = 1.0 → 1

→ **10.0101**<sub>2</sub>   (Probe: 2 + 1/4 + 1/16 = 2.3125)

**Aufgabe 4.** Wandeln Sie in eine Binärzahl um:  0.4375<sub>10</sub> = …

0.4375 · 2 = 0.875 → 0;  0.875 · 2 = 1.75 → 1;  0.75 · 2 = 1.5 → 1;  0.5 · 2 = 1.0 → 1

→ **0.0111**<sub>2</sub>   (Probe: 1/4 + 1/8 + 1/16 = 7/16 = 0.4375)

**Aufgabe 5.** Welche dieser Dezimalzahlen lässt sich als Binärbruch mit endlich vielen Nachkommastellen exakt darstellen?

**0.375** = 0.011<sub>2</sub> (= 1/4 + 1/8).

*Hinweis: Endlich darstellbar sind nur Summen von Zweierbrüchen (1/2, 1/4, 1/8 …). 0.1, 0.2 und 0.3 werden periodisch (z. B. 0.1 = 0.0001'1001'1001…<sub>2</sub>). Das ist die Überleitung zu den Gleitkommazahlen.*
