# Zweite Beispielwebseite (modernes Design)

Dieselben Inhalte und Seiten wie `../musterloesung-webseite/` (Startseite, Wer bin ich, Fotos,
Kontakt), aber mit modernem, bewusst komplexerem Design: CSS-Variablen, Flexbox, Grid,
responsive (Handy/Desktop), Dark Mode, feste Navigation, Hero-Bereich, Karten und Hover-Effekte.
Nur zum Zeigen in der Vorlesung; die einfache Musterlösung vermittelt die Basiskonzepte.

Vergleich der Konzepte: dieselbe Struktur (`header`, `nav`, `main`, `footer`, Tabelle `#cv`,
Galerie `#album`, Formular `#bmi`), nur ein anderes `style.css`. Das zeigt gut, wie Inhalt
und Design getrennt sind. Zum Ansehen `index.html` im Browser öffnen.

Von der Website nicht verlinkt, aber von GitHub Pages ausgeliefert (siehe README der einfachen Musterlösung).
