# Schriften

Alle Schriften liegen bewusst im Repository und werden **nicht** von einem
externen Dienst (Google Fonts o. ä.) nachgeladen. Dadurch entsteht beim Aufruf
der Seite kein Request an Dritte – es werden keine IP-Adressen an fremde Server
übermittelt.

Die Dateien sind auf den Zeichensatz „latin" reduziert (Subset von Fontsource).

| Datei | Schrift | Lizenz |
|---|---|---|
| `inter-latin-wght-normal.woff2` | Inter (variabel, 100–900) | SIL Open Font License 1.1 |
| `source-serif-4-latin-wght-normal.woff2` | Source Serif 4 (variabel, 200–900) | SIL Open Font License 1.1 |
| `source-serif-4-latin-wght-italic.woff2` | Source Serif 4 kursiv (variabel) | SIL Open Font License 1.1 |
| `ibm-plex-mono-latin-400-normal.woff2` | IBM Plex Mono Regular | SIL Open Font License 1.1 |
| `ibm-plex-mono-latin-500-normal.woff2` | IBM Plex Mono Medium | SIL Open Font License 1.1 |

Die SIL OFL erlaubt Verwendung, Weitergabe und Einbettung – auch kommerziell –
solange die Schriften nicht einzeln verkauft werden und der Lizenztext
mitgeliefert wird. Volltext: <https://openfontlicense.org/>

Bezugsquelle: <https://fontsource.org/> (Stand: August 2026)

Geladen wird eine Schrift nur, wenn ein Design sie tatsächlich verwendet. Im
Standarddesign kommen ausschliesslich Systemschriften zum Einsatz; dort wird
keine dieser Dateien übertragen.
